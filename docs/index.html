The 3-Question Leadership Reliability Audit

Ask your AI engineering leads these three questions before deploying LLMs with database access:

1. Session Tracking: "Does our agent track its cumulative query count ($M$), or is each SQL query evaluated in isolation?"
2. Small-Slice Thresholds: "When the agent narrows down to small cohorts ($N < 50$), does the bar for calling something 'significant' automatically rise?"
3. Out-of-Sample Verification: "Do we mathematically verify that insights will replicate on unseen data before executives act on them?"
